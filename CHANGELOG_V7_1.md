# Ruvia V7.1 — Site Management

- Site URLs are now generated automatically from the project name.
- Spaces, accents and symbols are normalized into clean slugs.
- Site cards now include a Copy URL action.
- Site cards now include Delete without opening the editor.
- Delete removes the site, public publication, public requests and memberships.
- Renaming a project automatically derives its next slug; published sites show a republish notice when the URL changed.
- Firebase rules allow an owner to delete their Site root safely.
