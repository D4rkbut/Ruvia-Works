# Ruvia V7.2 — Code IDE

## Editor Ruvia Code
- Monaco Editor integrado às abas HTML, CSS, JavaScript e JSON.
- Syntax highlighting por linguagem, números de linha, folding, indent guides e bracket pair colorization.
- Autocomplete nativo de HTML/CSS/JavaScript/JSON.
- IntelliSense customizado da API `Ruvia.*` com documentação básica.
- Sugestões para bindings, loops, condições, componentes e atributos Ruvia.
- Auto fechamento de tags HTML (`<div>` → `</div>`) e pares `()`, `[]`, `{}`, aspas e template strings.
- Snippets com Tab stops para loops, condições, actions, Canvas e runtime.
- Expansão fullscreen do editor para trabalhos maiores.
- Decorações próprias para `{{ bindings }}`, `{% controles %}` e atributos `ruvia-*`.
- Fallback seguro para o textarea anterior se o Monaco/CDN estiver indisponível.

## Atalhos úteis
- `Ctrl+Space`: abrir sugestões.
- `Tab`: indentar / avançar em snippet.
- `Shift+Tab`: remover indentação.
- `Alt+↑/↓`: mover linha.
- `Ctrl+Z / Ctrl+Y`: undo / redo.
- `Ctrl+F`: buscar.
- `Ctrl+H`: substituir.
- `Ctrl+/`: comentar linha (JS/CSS conforme suporte da linguagem).
