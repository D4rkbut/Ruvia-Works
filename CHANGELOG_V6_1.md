# Ruvia V6.1 — Code Docs

- Nova documentação viva de Ruvia Code dentro do Site Editor.
- Acesso por **Docs** na barra superior do editor.
- A documentação é renderizada pelo próprio `RuviaCodeFrame`, servindo também como demonstração real da engine.
- Navegação por capítulos e layout responsivo.
- Exemplos de bindings, loops, condições, filtros, Data Context, ações, formulários, componentes, CSS/tokens e segurança.
- Receita completa de vitrine conectada.
- Nova ação segura `ruvia-action="copy"` / `ruvia-copy="..."` para copiar snippets sem JavaScript arbitrário.
- Service Worker atualizado para `ruvia-v6.1-code-docs`.
