# Ruvia V7.4 — App Visual Refresh

## Objetivo
Aproximar a estética do app principal da linguagem visual do site de documentação do Ruvia Code.

## Mudanças visuais
- nova paleta inspirada no docs: base ink / forest / lime
- hero inicial mais cinematográfico e tecnológico
- topbar e bottom dock com visual dark glass
- botões primários agora usam lime como destaque
- cartões, sheets e inputs com superfícies mais sofisticadas
- login, onboarding e editor de sites alinhados à nova identidade
- sombras, raios e bordas refinados para aparência mais premium

## Sem quebrar a arquitetura
- nenhuma mudança estrutural na modelagem de dados
- Firebase, módulos e runtime preservados
- refresh feito majoritariamente em CSS / identidade visual
