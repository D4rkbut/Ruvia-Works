# Ruvia V6.0 — Ruvia Code

- adiciona bloco `Ruvia Code` ao editor visual;
- adiciona modo de página inteira em código;
- cria Ruvia Template Language com bindings, loops, condicionais e filtros;
- adiciona contexto seguro de Site, Business, Produtos, Serviços, Recursos e JSON local;
- adiciona componentes seguros para WhatsApp, Contato, Booking, Produtos e Serviços;
- permite ações `ruvia-action` e formulários `ruvia-form` em markup totalmente customizado;
- adiciona parser com diagnóstico de blocos não fechados/tags inválidas;
- adiciona status de validade no editor;
- executa o resultado em iframe sandboxado, sem JavaScript arbitrário do usuário;
- adiciona capabilities específicas de Code para planos futuros;
- Draft schema passa para 4;
- snapshot público passa para schema 5;
- Service Worker passa para `ruvia-v6.0-ruvia-code`.
